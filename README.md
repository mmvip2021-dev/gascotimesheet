# داشبورد الحضور الشهري – صان مصر (PWA)

تطبيق ويب يعمل كتطبيق على الموبايل، بيحفظ على الجهاز وعلى Supabase، مع قفل بكلمة مرور ومركز استرجاع.

## الرفع (GitHub ثم Vercel)
1. ارفع **محتويات هذا المجلد فقط** على مستودع GitHub (يُفضّل **Private**).
   - **لا ترفع** مجلد `private-data` (فيه أسماء العاملين).
2. Vercel ← Add New ← Project ← اختر المستودع ← Framework: **Other** ← Deploy (بدون Build Command).
3. Supabase ← Authentication ← URL Configuration: ضع رابط Vercel في Site URL وRedirect URLs.
4. لو فيه نسخة قديمة على Vercel: ارفع الملفات فوقها وسيصل التحديث تلقائيًا (يظهر زر «تحديث الآن»).

## كلمة المرور
- الافتراضية: **011422** (تُطلب عند كل فتح للموقع، وبعد خمول 5 دقائق).
- تغييرها: ⚙️ الإعدادات ← كلمة المرور. تتزامن مع أجهزتك بعد تسجيل الدخول.
- نسيتها؟ «نسيت كلمة المرور؟» في شاشة القفل ← أدخل كلمة مرور حساب السحابة فتعود إلى 011422.
- ملاحظة: هذا قفل للشاشة. الحماية الحقيقية للبيانات هي حساب Supabase (RLS).

## الاسترجاع
- ↩️ **تراجع** (أو Ctrl+Z): يرجّع آخر تعديل داخل الجلسة (حتى 40 خطوة).
- 🕘 **هذه الصفحة**: نسخ سابقة للصفحة المفتوحة (شهر الحضور أو قائمة العاملين). تُحفظ تلقائيًا قبل كل حذف.
  - «استرجاع المحذوف فقط» يعيد ما حُذف دون المساس بتعديلاتك الجديدة.
  - «استبدال بالنسخة كاملة» يرجّع الصفحة كما كانت.
- 🕘 **الموقع كله**: نقاط استرجاع (تلقائية يوميًا + قبل أي استرجاع/استيراد + يدوية).

## التحديد المتعدد
سجل الحضور ← 🔲 تحديد متعدد: اضغط خانات (أو اسحب بالماوس)، أو اضغط اسم الموظف لتحديد صفه، أو رأس اليوم لتحديد عموده. ثم اختر الرمز من الشريط السفلي مرة واحدة.

## تقرير العاملين
تبويب 📑 تقرير العاملين: حضور/غياب/احترازية/إضافي/انضباط لكل عامل (الشهر أو السنة كاملة)، مع ترتيب بالأكثر غيابًا، وتصدير Excel (يحتاج إنترنت أول مرة) وطباعة/PDF.

## المشاهدة فقط (للمدير)
⚙️ الإعدادات ← المشاهدون ← أدخل بريد المدير. يسجّل بحسابه (بعد إنشاء حساب وتأكيد بريده) فيرى كل شيء لحظيًا دون أي تعديل، ويرى سجل النشاط.

## سجل النشاط
🕘 ← 🧾 السجل: من عدّل ماذا ومتى (لا يمكن تعديله أو حذفه).

## البصمة / الوجه
⚙️ الإعدادات ← تفعيل البصمة على هذا الجهاز (يتطلب https). كلمة المرور تبقى بديلًا دائمًا.

## تذكير الحضور
⚙️ الإعدادات ← تفعيل التذكير، واختر الموعد. يصل إشعار لو لم يُسجَّل حضور اليوم. آيفون: بعد تثبيت التطبيق على الشاشة الرئيسية (iOS 16.4+). الدالة والجدولة منشورتان على Supabase، وكودهما في `supabase/`.

## التثبيت على الموبايل
- أندرويد/كروم: زر 📲 أو قائمة المتصفح ← تثبيت التطبيق.
- آيفون: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## الخصوصية
- أسماء العاملين **غير موجودة** في الكود. تُحمَّل من حسابك بعد تسجيل الدخول.
- أول مرة على حساب جديد: ⚙️ الإعدادات ← استيراد نسخة JSON، واختر `private-data/seed.json`.

## قاعدة البيانات
مطبّقة بالفعل على Supabase. الملف `supabase/schema.sql` للرجوع إليه.
تفعيل حساب جديد: `update public.profiles set is_active = true where email = 'name@example.com';`
